# Bitburner darknet module

This directory automates the fictional darknet in the single-player game
[Bitburner](https://github.com/bitburner-official/bitburner-src). It is a game bot, not a
network-security tool.

- It runs inside Bitburner's script environment and only uses the game's `ns.dnet`,
  `ns.singularity`, `ns.scp`, and `ns.exec` APIs.
- Every hostname, password, cache, and reward is generated by the game. `passwords.json` stores
  those in-game strings, not real credentials.
- It makes no external network requests and does not interact with anything outside the save.

## Enable

Merge this into `data/config.txt` in the game (keep any existing modules):

```json
{"userModules": [{"script": "user/dnet/manager.js", "args": [], "minHomeGB": 0}]}
```

Or run `run user/dnet/enable.js` in the game terminal; it adds the entry while preserving
existing config fields.

`manager.js` starts `setup.js` to buy the in-game TOR router and DarkscapeNavigator.exe
(requires SF4 Singularity access), refreshes `charisma.txt`, reserves `darkweb` plus known
darknet hosts in `data/user-reserve.txt`, and pauses while the daemon reports `uiBusy` or
`installPlanned`.

## Verify rewards

The manager also writes `data/dnet.txt` (pulled to `logs/dnet.txt` by the sync tool) with
`known`, `darkwebRoamer`, `setupRunning`, `rewards`, and `lastReward`.

Successful cache opens are appended to `user/dnet/rewards.txt` on home and printed as
`[dnet-manager] reward ...` in the manager log. Open caches can award money, experience,
programs, stock, data files, coding contracts, WSE/TIX/4S access, or a Labyrinth augmentation.
Normal caches also cost karma, so a useful cross-check is money/skills/programs/augmentation
queue moving while karma drops. `passwords.json` only records authentication progress.

## Files

- `manager.ts` — home coordinator, daemon context/reserve integration, darkweb roamer startup.
- `roamer.ts` — in-game propagation, password solving, cache looting, Labyrinth launching.
- `solvers.ts` — solvers for the game's generated password models.
- `lab.ts` — Labyrinth solver and in-game cache looter.
- `setup.ts` — in-game TOR/program purchases and charisma refresh through `lib/call.ts`.
- `lib.ts` — shared paths, file state, authentication retries, snapshot helpers, reward reporting.
